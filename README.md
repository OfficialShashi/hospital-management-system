# 🏥 Hospital Management System (HMS)

A Full Stack Hospital Management System developed using **Java, Spring Boot, React.js, and MySQL** to streamline hospital operations through role-based access and integrated modules.

## 🚀 Project Overview

The Hospital Management System (HMS) is designed to manage hospital activities digitally, including patient records, doctor management, appointments, and laboratory operations.

The application uses REST APIs for frontend-backend communication and JWT-based authentication for secure access.

## 🧪 Laboratory Module

The Laboratory Module supports the following workflow:

1. Doctors create laboratory orders for patients.
2. Lab Technicians view laboratory orders.
3. Lab Technicians collect patient samples.
4. Laboratory processing is initiated.
5. Test results are submitted.
6. Order status is updated to `COMPLETED`.

**Testing Status:** Successfully verified the complete laboratory workflow using two test orders.

## ⚙️ Project Setup

### Backend Setup

1. Clone the repository.
2. Open the backend folder in Spring Tool Suite or IntelliJ IDEA.
3. Configure MySQL database credentials in your local application configuration.
4. Run the Spring Boot application.

### Frontend Setup

1. Open the frontend folder in VS Code.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the URL displayed in the terminal.
